# 협업 규칙

> 공유 Google Colab에서 작업하고, 작업이 끝난 시점의 노트북을 `main.ipynb`로 다운로드하여 GitHub에 반영합니다.

## 1. 기준 파일

- 작업 파일명은 항상 `main.ipynb`로 통일합니다.
- GitHub `main` 브랜치의 `main.ipynb`를 최종 기준본으로 사용합니다.
- 공유 Colab은 공동 작업 공간으로 사용합니다.
- `main` 브랜치에 직접 push하지 않습니다.

## 2. 작업 시작 전

- 작업 시작 전에 팀 채널에 메시지를 남겨, 동시에 여러 명이 같은 셀을 수정하지 않습니다.
- 동시 작업이 필요하다면 Colab을 복제하여 작업한 뒤, 완성된 셀을 공유 Colab에 반영합니다.
- 공유 Colab이 GitHub `main`의 최신 내용인지 확인합니다.
- 최신본이 아니라면 먼저 GitHub의 `main.ipynb`를 Colab에 반영합니다.

## 3. Colab 작업 규칙

- 담당한 섹션과 셀만 수정합니다.
- 다른 팀원이 작업 중인 셀은 수정하거나 이동하지 않습니다.
- 셀 제목을 Markdown으로 작성하여 담당 영역을 구분합니다.
- 앞선 셀을 임의로 실행해야만 동작하는 숨은 의존성을 만들지 않습니다.
- 위에서 아래로 전체 실행했을 때 동작하도록 작성합니다.
- 개인 PC의 절대경로를 코드에 넣지 않습니다.

## 4. 데이터와 실행 환경

- 원본 데이터는 GitHub에 커밋하지 않습니다.
- Colab과 로컬 모두 기본 상대경로를 사용합니다.
- 데이터가 없으면 공식 URL에서 자동으로 다운로드하도록 합니다.
- `.env`가 없어도 기본값으로 실행되어야 합니다.
- 로컬에서 경로 변경이 필요하면 `.env.example`을 복사해 `.env`를 생성합니다.
- 패키지를 추가하면 설치 셀과 `requirements.txt`를 함께 수정합니다.

## 5. Git 반영 절차

작업을 마치면 공유 Colab에서 노트북을 다운로드합니다.

```text
파일 → 다운로드 → .ipynb 다운로드
```

다운로드한 파일명을 `main.ipynb`로 맞춘 뒤 저장소의 기존 파일을 교체합니다.

```bash
git switch main
git pull origin main
git switch -c feature/<작업명>

# 다운로드한 main.ipynb로 기존 파일 교체

git add main.ipynb
git commit -m "feat: <작업 내용>"
git push origin feature/<작업명>
```

그 후 GitHub에서 PR을 생성합니다.

## 6. PR 및 병합 규칙

PR에는 다음 내용을 간단히 작성합니다.

- 작업한 셀 또는 섹션
- 주요 변경 내용
- 실행 확인 여부
- 남은 문제

병합 전 확인합니다.

- [ ] 최신 `main`을 기준으로 작업했다.
- [ ] 다른 팀원의 작업을 덮어쓰지 않았다.
- [ ] `main.ipynb` 파일명이 유지됐다.
- [ ] 개인 경로와 불필요한 파일이 포함되지 않았다.
- [ ] Colab 런타임을 재시작하고 전체 실행했다.
- [ ] 팀원 2명 이상이 변경사항을 확인했다.

팀원 2명 이상의 확인이 끝나면 **DayeonOh가 `main`에 병합합니다.**

## 7. 충돌 방지 원칙

- 한 시점에는 한 명만 `main.ipynb`를 GitHub에 반영합니다.
- PR의 최종 Merge는 DayeonOh만 진행합니다.
- 먼저 작업을 마친 사람이 PR을 병합한 후 다음 사람이 최신 `main`을 기준으로 반영합니다.
- PR이 열려 있는 동안 다른 사람은 이전 버전의 노트북을 커밋하지 않습니다.
- 병렬 작업이 필요하면 각자의 담당 셀을 별도 노트나 코드로 준비한 뒤, 공유 Colab에서 순서대로 통합합니다.
- `.ipynb` 충돌은 직접 합치기 어렵기 때문에 GitHub에서 자동 병합하지 않습니다.
- 충돌 발생 시 두 노트북을 임의로 합치지 말고 공유 Colab에서 필요한 셀을 다시 통합합니다.
- `git push --force`는 사용하지 않습니다.

## 8. 최종 실행 기준

병합 전 공유 Colab에서 다음 순서로 검증합니다.

```text
런타임 다시 시작
→ 모든 출력 삭제
→ 위에서 아래로 전체 셀 실행
→ 데이터 다운로드 확인
→ 차트·통계·모델·리포트 생성 확인
```

로컬에서도 가능한 경우 다음을 확인합니다.

```bash
pip install -r requirements.txt
jupyter notebook main.ipynb
```

> 핵심 원칙: **공유 Colab에서 통합하고, 작업 완료 시점의 전체 노트북을 `main.ipynb`로 커밋한다.**
